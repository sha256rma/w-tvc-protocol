Reference Test Bench

Which test runs on which model, what each test has to tell apart, and what every run measured. Built from reference/plan.json and reference/runs/; a number that isn't in one of those files doesn't appear here. Blank means not measured yet.

Model × test matrix

Rows are models pinned to one Hugging Face commit. Columns are the batteries, keyed to SPOT catalogue check IDs. Fits assumes 16-bit weights must stay under 80% of GPU memory, leaving room for the cache; the T4 has no bf16, so it runs fp16.

Can each test tell the pair apart?

A reference test is only worth running if it separates the claimed model from what a provider would plausibly serve instead. Each row is one substitution case; the PW-01 column is measured, the rest is what we expect and which battery has to prove it.

PW-01 token counts

The measured reference: tokens per string with each model's own tokenizer.json. Highlighted cells differ from Qwen2.5. Models with identical rows are indistinguishable to this check.

GPU reference runs

Each row is one node of the OpenResearch experiment tree, run on one NVIDIA L4 with vLLM. det is how many of 32 greedy answers came out the same alone and inside a full batch. The p-values are self-checks: two random halves of the same samples, which should not look different (large p is good).

Honest providers vs substitutes

How often each test flags a sample set against the batch-invariant reference, with the threshold set at the 95th percentile of the declared honest set (each honest member judged only against the others). Honest rows should be near 0; substitute rows should be near 1. Columns are samples per prompt.
